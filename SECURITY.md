# Security Policy

Honey House Tech takes the security of our platform and our MSP customers seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in any of our repositories or products, please report it privately rather than opening a public issue.

- Email: info@honeyhouse.tech
- Include a description of the issue, steps to reproduce, and any relevant logs or screenshots.

We will acknowledge your report as soon as possible and work with you to understand and address the issue.
